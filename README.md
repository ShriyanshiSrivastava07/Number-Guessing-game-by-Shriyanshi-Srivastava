# 🎯 Number Guessing Game in Python

A simple **Number Guessing Game** built using Python as my second basic programming project.

The computer randomly selects a number, and the player has to guess the correct number. The program provides feedback to help the player find the correct answer.

## 🚀 Features

* 🎲 Generates a random number
* ⌨️ Takes guesses from the user
* 💡 Gives hints if the guess is too high or too low
* ✅ Checks whether the guess is correct
* 🐍 Built completely using Python

## 🛠️ Technologies Used

* **Python**
* `random` module
* Basic Python concepts such as:

  * Variables
  * User input
  * Conditional statements
  * Loops
  * Random number generation

### 1. Clone the repository


### 2. Open the project folder

```bash
cd Number-Guessing-game-by-Shriyanshi-Srivastava
```

### 3. Run the Python program

```bash
python numberguessinggame.py
```

## 🎮 How to Play

1. Run the program.
2. The computer will generate a random number.
3. Enter your guess.
4. The program will tell you whether your guess is too high or too low.
5. Keep guessing until you find the correct number.
